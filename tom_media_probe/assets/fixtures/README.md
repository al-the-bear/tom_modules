# Fixture videos

Four videos of 10 seconds for the extraction probe, written by
`tool/make_fixtures.sh` with FFmpeg 8.0.1 on 2026-11-25.

| File | Container | Video | Sound |
| --- | --- | --- | --- |
| `h264_aac.mp4` | MP4 | H.264 High | AAC-LC |
| `hevc_aac.mov` | QuickTime (MOV) | H.265 / HEVC Main, tagged `hvc1` | AAC-LC |
| `vp9_opus.webm` | WebM | VP9 | Opus |
| `h264_aac.mkv` | Matroska (MKV) | H.264 High | AAC-LC |

All four: 320×240, 30 frames a second, a key frame every 60 frames (2 s),
about 300 kbit/s; the sound is a 440 Hz sine, stereo, 44.1 kHz (48 kHz in
the WebM).

## What a frame shows

FFmpeg's `testsrc2` pattern, and in the top strip its own frame number: 20
squares of 16×24 pixels, square *b* white when bit *b* of the number is set.
A frame an extractor returns therefore says which frame it is
(`frameNumber` in `lib/src/extraction.dart`, `tool/frame_numbers.py`).
